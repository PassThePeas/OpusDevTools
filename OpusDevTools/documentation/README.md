# 🚀 Directory Opus Developer Tools (OpusDevTools)

**OpusDevTools** is a development suite designed for JScript scripting within Directory Opus. It bridges the gap between the native scripting engine and modern IDE features without requiring external dependencies like Node.js.

### ✨ Triple Objective
1. **IntelliSense Mastery**: Full type safety and autocompletion for the Directory Opus Object Model.
2. **Task Automation**: Eliminate repetitive manual tasks like JSDoc injection and include referencing.
3. **Productivity Boost**: Provide a collection of specialized code snippets for common Directory Opus scripting patterns.

---

### 📂 File Structure
| Path | Description |
| :--- | :--- |
| `.vscode/` | IDE configuration, snippets, and task definitions. |
| `OpusDevTools/data/` | Internal operational data (Manifest & update tracking). |
| `OpusDevTools/typings/` | The core TypeScript definition files (`.d.ts`). |
| `OpusDevTools/documentation/` | Technical guides and AI generation methodologies. |
| `jsconfig.json` | VS Code workspace configuration. |

### 💻 VS Code Integration

#### 1. Advanced Typings & Extensibility
* **Core API**: `dopus.d.ts` provides full signatures for the Directory Opus API.
* **Global Scope**: `global.d.ts` defines essential globals like `DOpus` and `Script`.
* **User Customization**: `user_custom.d.ts` acts as a hub. Add your own `/// <reference path="..." />` here if any.
* **Include Support**: Beyond the core API, the system manages your private libraries. By adding your own `inc_*.d.ts` files in the appropriate folder, your utility functions become globally recognized by IntelliSense.

#### 2. VS Code Helpers
Three specialized tasks are available (`Ctrl+Shift+B`):
* **Build Index**: Compiles the global index linking `dopus.d.ts`, `global.d.ts`, `user_custom.d.ts`, and all detected include definitions.
* **Fix Types**: Processes the current file to inject standardized include directives and JSDoc types for Opus events, command entry points, and custom columns.
* **Generate Minified Typings**: Creates a minified version of the API to reduce token usage when using AI Studio for library generation. (See `AI_STUDIO_METHOD.md` for details).

### ⚙️ Directory Opus Mechanics (The Engine)

The system is powered by the `OpusDevTools.js` script add-in, exposing commands that can be triggered from VS Code or directly within Opus.

#### `OpusDT_Install`
Automates the deployment by fetching the **latest release from GitHub**. It uses a **Manifest system** (MD5 hashing) to update core files while protecting your local modifications by creating `.template` files. It also automatically patches system paths in `dopus_env.cmd`.

#### `OpusDT_FixTypes`
The primary transformation tool. It features a safety-first approach:
* **Automatic Backups**: Every processed file is timestamped and backed up in the `Backups FixTypes` folder before modification.
* **VS Code Mode**: When called from the IDE, it modifies the active file directly.
* **Batch Mode**: When called from Opus, it processes selected files. Results are generated by default in `/dopusdata/Script Addins/tmp_fix_types` (customizable via the `DEST_FOLDER` parameter). This allows you to review the automated changes before deciding to promote them (replacing the original files).

#### Additional Commands
* **`OpusDT_GenerateIndex`**: Manages the rebuilding of the Typings Index.
* **`OpusDT_GenerateLightTypings`**: Handles the minification of the API for AI context optimization.

### 🛠️ UI Integration
In addition to the script, a **`.dcf` file** is provided. This file contains a ready-to-use Menu button for your Directory Opus toolbars, granting quick access to all maintenance and installation commands directly from the lister.
